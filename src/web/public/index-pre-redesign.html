Filter Einstellungen

Gleitend Mitteln (MA): Robust gegen Ausreißer, gute Rauschunterdrückung bei moderatem Verzögerung.
Schwellwert: Unter diesem Wert gilt der Sensor als nicht gedrückt (0). Richtwerte: 0–500 = sehr empfindlich; 500–1000 = normal; >1000 = weniger empfindlich (ignoriert leichte Berührungen).
Max-Druck für Normalisierung (0–1): ADC-Wert, der 100% entspricht. Standard: 4000. Höher setzen (z. B. 4095) wenn sehr hohe Drücke nötig sind, sonst sättigt der Joystick früher.
